# sisy.study

Resource library landing page for the SISY platform.

**Live site:** https://sisy.study

## About

Templates, guides, and checklists for women experts preparing bios, CFPs, and stage-ready materials. Part of the [SISY ecosystem](https://sisy.world).

## Sections

- Hero - "Resources that prepare you for the stage"
- Resource category cards (Bio Templates, CFP Templates, Speaker Guides, Prep Checklists)
- Featured resource cards
- Free sampler download (marble gradient background)
- Premium pack pricing (Starter €19 / Expert €49 / Pro €99)
- CTA

## Tech

Built with [Hugo](https://gohugo.io/). Deployed to GitHub Pages via Actions.

## Local development

```bash
hugo server -D
```

## Deployment

Auto-deploys on push to `main` via `.github/workflows/deploy.yml`.
